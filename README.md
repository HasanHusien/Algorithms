# 🧠 Algorithms Concepts

This repository contains basic algorithm concepts implemented in JavaScript And Python.  
It focuses on understanding how search algorithms work and how their runtime differs.

---

## ⚙️ Common Runtime Complexities

When analyzing algorithms, we use **Big O Notation (O)** to describe how the runtime grows as input size increases.

| Notation | Name | Description | Example |
|-----------|------|--------------|----------|
| **O(1)** | Constant Time | Always takes the same time, no matter the input size. | Accessing an array element |
| **O(n)** | Linear Time | Time grows directly with input size. | Linear Search |
| **O(log n)** | Logarithmic Time | Input size reduces by half each step. | Binary Search |
| **O(n²)** | Quadratic Time | Grows rapidly with nested loops. | Bubble Sort |
